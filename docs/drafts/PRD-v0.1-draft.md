# PRD: SV Career (인사팀 채용·교육 블로그)

## 1. 기본 정보
- 문서 버전: v0.1
- 작성일: 2026-11-24
- 작성자: 이은정
- 관련 자료: https://sylvvuu.github.io/blog/ , https://github.com/sylvvuu/blog

## 2. 개요
- 핵심 문제: 청년 구직자가 홈에 들어와도 채용 공고 글까지 가는 경로가 길어서, 공고를 열어 보지 못하고 떠날 수 있다. GA 기준 방문 44명 중 공고 글을 연 사람은 6명(13.6%)이다.
- 대상 사용자: 지원 전에 채용 공고를 찾아보는 청년 구직자, 특히 신입 구직자
- 이번 해결 범위: 홈에서 공고 글까지의 접근 경로

## 3. 문제 정의
### 3.1 현황 근거
- 기간: 2026-10-27 ~ 11-23 (GA4 스냅샷)
- 방문 44명, 공고 글 열람 6명(13.6%), 완독 5명, 지원 클릭 2명(6회)
- 신입 공고 조회 15회(활성 사용자 11명), 경력 공고 조회 12회(활성 사용자 4명)
- 한계: 표본이 작고, 글 열람 이벤트명이 11/18에 바뀌었으며, 관리자 접속이 일부 포함되어 있다. 공고는 가상의 회사 공고다.

### 3.2 후보 문제 3개
1. 홈에서 공고 글까지의 접근 경로가 길다
2. 공고를 읽고도 지원으로 이어지지 않는다
3. 신입과 경력 구직자의 정보 요구가 달라 보이는데 맞춰 주지 못한다

### 3.3 우선순위 결정
- 선택한 문제: 1번 (홈에서 공고 글까지의 접근 경로)
  - 사용자가 실제로 겪는 장면이고, 글 열람 비율이라는 기록이 있다.
  - 홈 구성을 바꾸면 바로 해결 방안과 연결된다.
- 탈락한 문제와 이유
  - 2번: 공고와 회사가 가상이라 지원 전환을 실제 문제로 검증할 수 없다.
  - 3번: 신입 공고와 경력 공고 두 개만 비교한 근거라서, 측정을 보강한 뒤 다음 단계에서 검토한다.

### 3.4 최종 문제 정의
청년 구직자는 SV Career 홈에 들어와도 소개 영역과 날씨 영역을 지나야 공고 글을 열 수 있어서, 원하는 공고를 찾지 못하고 떠날 수 있다.

## 4. 해결 방안
- 홈 상단 소개 블록 제거 (11/24 반영)
- 홈에서 공고 목록이 바로 보이도록 배치
- 현재 구현 상태: 사이트명 SV Career 변경, 공채 속보 이벤트(job_list_view, job_item_click) 추가
- 기대 효과: 홈 방문 대비 공고 글 열람 비율 증가

## 5. 지표
- 핵심 지표: 홈 방문 대비 공고 글 열람 비율
- 보조 지표: 공채 속보 목록 조회 수(job_list_view), 공고 링크 클릭 수(job_item_click)
- 측정 방법: GA4 이벤트, 변경 전(10/27~11/23)과 변경 후 비교
- 한계: 표본이 작고, 이벤트 이름 변경 이력이 있어 같은 기준으로 비교하기 어렵다.

## 6. 기능 요구사항
- 홈 화면에서 최신 공고 목록을 바로 보여 준다.
- 공고 링크 클릭을 기록한다. 공고 제목은 보내지 않고 순번만 보낸다.

## 7. 비기능 요구사항
- 공고 API 호출이 실패하면 목록 영역이 사라진다. 개선 필요: 안내 문구 표시
- 개인정보를 수집하지 않는다.

- 신입·경력 구분 맞춤 측정기준 등록 후 3번 후보 재검토
- 공고 API 실패 시 안내 문구 추가

## 10. Q&A
- Q. 왜 지원 전환을 문제로 삼지 않았나요? A. 가상의 공고라서 실제 지원 행동으로 이어지지 않기 때문입니다.
- Q. 신입 조회가 많은데 왜 신입 기능을 먼저 만들지 않았나요? A. 공고 2개 비교라서 근거가 약하고, 측정을 먼저 보강하기로 했습니다.
