## 2. 기능 범위 대비 현황 (PRD C.5 완료 기준)

- 완료 확인: 채용 목록과 드롭다운, 관리자 글 수정·삭제 전용 전환, AI 키 서버 환경 변수 보관, 이벤트 측정 설계.
- 배포 후 확인 필요: 교육 패널, 직업 정보 검색, AI 답변 꺼짐 시 기존 검색 복귀, 이벤트 10개 GA4 수신.
- 미실시: 평가 질문 10개, 근거 없을 때 "목록에서 찾을 수 없습니다" 확인.
- 오늘 추가된 작업: GA4 방문자·공고 클릭을 관리자 화면에 연결 (Workload Identity 방식, 키 파일 없음). PRD에는 이 항목이 없습니다. 관리자 "조회수 확인" 유지(C.4)의 확장으로 볼 수 있으나, 명세에 적히지 않았습니다.

## 3. 범위 이탈

1. 청년정책 요청: PRD 2장에서 청년정책은 범위 밖입니다. 그런데 챗봇에 "청년정책 연결해줘"를 입력하면 "관련 글을 찾지 못했습니다"만 나옵니다. 범위 밖 질문에 대한 안내 문구가 없어서 사용자가 막다른 길로 느끼는 문제입니다. 해결 방향은 두 가지입니다: (a) 범위 밖이라고 명시하고 청년정책 훑어보기 외부 링크를 안내, (b) 범위를 넓혀 PRD를 변경. 선택은 사용자 몫입니다.
2. 기능 선행: 11/24 13시 무렵 기능 구현이 PRD 정리보다 앞섰다고 실패 기록에 적혀 있습니다. 이후 교육·직업 칸, AI 상담, GA4 연결이 늘었습니다. 기획서 기준으로 보면 F5(규칙 기반 검색)와 F6(AI 상담)의 역할이 겹쳐 있습니다.
3. 측정 기준 변경: 3.1 샘플 기간 해석은 근거로 쓰지 않는다고 적었지만, 오늘 관리자 화면 연결로 실제 수치가 들어오면 PRD 3.1.0과 KR1 기준선을 새로 채워야 합니다.
