## 진행 중인 실패 (미해결)
- 관리자 접속이 구직자 데이터에 섞여 있음 → 내부 트래픽 정의 필요
- 공고 API 실패 시 목록이 아무 안내 없이 사라짐 → 안내 문구 필요
- 공고 이탈률 0% 값의 측정 방식이 불명확함
- 상담 API(`api/chat.js`)는 키 연결 전이라 실제 답변을 확인하지 못함 → 키 연결 후 질문 10개로 평가 (`docs/TEST_REPORT.md`)
- 교육 API 활용신청 승인 여부가 확인되지 않아 교육 패널을 실제 화면에서 보지 못함
- 채용 키가 Firestore 설정 문서에 있어 누구나 읽을 수 있음 → 서버 함수 이전 필요 (PRD 7장)
- 아이폰 로그인 복귀 확인 (06e0ce3 배포 후)
- 아이폰 AI 멘토 AI 답변 (Vercel 환경 변수 `ANTHROPIC_API_KEY` 확인 필요)
- 고용24 교육 목록 공개 주소 확인: GitHub Pages 주소는 더 이상 공개 주소가 아님
